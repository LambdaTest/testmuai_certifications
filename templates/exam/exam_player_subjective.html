{# ================= Answer ================= #} {% comment %} Three fields, all required. Submit stays disabled until every one is valid; a field shows its red hint only once something has been typed, so an empty form does not open as a wall of errors. The checks are a convenience, so the button is not live for a typo. ExamSheetFormSubjective repeats every one of them — the disabled attribute can be removed from devtools. Field names (github_repo, github_pr, test_ids) match the form, which reads request.POST by them. AFTER A REJECTED POST the form comes back bound, and two things follow from it: · the candidate's values are put back. x-model owns each input, so a value="" attribute would be overwritten; the values go in as data-* attributes and seed the Alpine state instead. Autoescaped, so a quote in a pasted link cannot break out of the attribute. · the server's error shows under its field, until that field is edited — then the live hint takes over, so two messages never argue. {% endcomment %}
