{# ---------------- Format guide ---------------- #}

First row is a header. Column names must match exactly; order does not matter.

Column Required Notes
question_text yes The question itself.
question_type no objective or subjective. Blank means objective.
question_difficulty no easy, medium or hard. Blank means easy.
marks no Subjective only. Objective questions are always worth 5.
option_1 … option_6 objective At least two. Leave the rest blank.
correct_option objective Which option is right, as a number: 1–6.
question_tags no Comma-separated. Lowercased on import.

Example

question_text,question_type,question_difficulty,option_1,option_2,option_3,correct_option,question_tags
"What does an explicit wait do?",objective,easy,"Polls until a condition holds","Sleeps for a fixed time","Retries the whole test",1,"waits"
"Explain the page object model.",subjective,hard,,,,,"design, patterns"
{% comment %} Stated here rather than discovered later. A CSV has nowhere to put a file, and inventing a path column would mean trusting a string from a spreadsheet to name something on disk. {% endcomment %}

Media cannot be imported

A CSV has nowhere to hold an image or an audio clip. Questions that need media must have it attached individually afterwards, from the Question Bank.
