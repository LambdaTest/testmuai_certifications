{# ================= Full-screen guard ================= #} {% comment %} Opaque white, not a translucent backdrop, and covering everything. The point is that the paper is not readable while the candidate is out of full screen — a dimmed overlay still shows the questions underneath, which is exactly what someone would window the tab to do. One way out, and it goes back into the exam. There is deliberately no "leave" button here: the clock is still running, so an exit at this moment would abandon a live attempt with no way back in. Leaving is a decision that belongs on the submit dialog, where the consequences are spelled out. The exit is still only recorded, never punished. An accidental Escape is not cheating, and the audit trail is what makes a pattern visible to whoever reviews a suspicious attempt. {% endcomment %}
