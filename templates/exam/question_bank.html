{% extends "base_staff.html" %} {% comment %} Question Bank — TEMPLATE ONLY. No url, view or delete route yet. Context it will need from a future apps.exam.views.question_bank: questions – Question rows, unpaginated for now and the view must fetch them as: Question.objects.select_related("question_subject") .prefetch_related("answers", "question_subject__exams") Without that, every card costs a query for its subject, another for its options, and another for the exams in its "Attached to" list. Three per row on a page built to show a whole bank. NO EDITING, deliberately. A question that has been sat is the record of what a candidate was asked, so changing its wording after the fact rewrites history that grading and appeals depend on. The card is read-only; the only action is removal. DELETE is unwired — both buttons are href="#". When it is built it must be a POST, not a link: a GET that destroys a row is one crawler or one prefetching browser away from clearing the bank. The shape to copy is cancel_booking_page / cancel_booking in views.py — a confirm page, then a POST. And per the design we settled on, it should be a *gated* delete: destroy only a question no candidate has answered, and retire the rest by flipping status to RETIRED. Search runs in the browser, as on Explore Exams and Explore Subjects: the rows are all on the page already. It matches question text, subject and tags, because an admin hunting for a question remembers its wording or its topic. {% endcomment %} {% block title %}Question Bank · TestMu AI Certifications{% endblock %} {% block staff_content %} {% comment %} `open` holds the index of the expanded card, so opening one closes the last — the same accordion rule the sidebar uses, for the same reason. Attached To Exams

{% comment %} Pills, not a dropdown. This is information, and a select box looks like an input — it promises that picking an entry does something, when there is nothing here to set. Nothing is attached by hand at all. Randomisation is the default selection mode, so a question is drawable by every exam on its subject, and that is what this lists. The only way to change the list is to create another exam on the subject. Detaching is not offered because there is no attachment to undo. The shape deliberately matches the status and difficulty badges on the card head, so the whole card reads as one body of read-only information. If manual selection is ever built this becomes a real relation, and only then does it earn a control. {% endcomment %}
