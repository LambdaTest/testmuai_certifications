{% extends "base.html" %} {% comment %} Shell for every admin and staff page: site chrome from base.html, plus the sidebar. Pages extend this and fill {% block staff_content %} — they should never carry their own copy of the nav. Sections with more than one destination expand; single-destination ones stay flat, since a chevron revealing one item is noise. ACCORDION. One `section` value lives on the outer x-data, so opening one closes whatever was open. Per-section state would let several stand open at once and push the sidebar past the fold. The section you are in opens on load, worked out from request.resolver_match.url_name — so no view has to pass anything, and there is no open/closed state to persist across page loads. The unfold is a CSS grid trick rather than a plugin: animating grid-template-rows from 0fr to 1fr reaches the content's natural height, which a plain height transition cannot do. Alpine's x-collapse would mean loading @alpinejs/collapse on top of the core build. Unbuilt destinations are href="#". Wire them as the views appear. {% endcomment %} {% block content %} {% with url_name=request.resolver_match.url_name %}
